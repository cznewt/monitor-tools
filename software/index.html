    Software Documentation¶

    This document lists the software and tools installed in the monitor-tools Docker image, as defined in monitor-tools/docker/Dockerfile.

    Core Tools¶

    Tool Version Description
    Just 1.52.0 A handy command runner.
    YQ Latest A portable command-line YAML processor.
    Go 1.25.3 Go programming language runtime.
    Vale 3.14.2 A syntax-aware linter for prose.
    Vendir 0.45.4 Declarative way to sync any number of directories from different sources.
    uv 0.11.19 An extremely fast Python package installer and resolver.

    Jsonnet Ecosystem¶

    Tool Version Description
    Go-Jsonnet 0.22.0 Google's implementation of Jsonnet in Go.
    Jrsonnet 0.5.0-pre98 A fast Jsonnet implementation in Rust.
    JB (Jsonnet Bundler) 0.6.0 Package manager for Jsonnet.
    Mixtool Latest Helper for working with Prometheus Mixins.

    Monitoring Tools¶

    Grafana¶

    Tool Version Description
    Grizzly (grr) 0.7.1 A toolkit for managing Grafana resources as code.
    Grafanactl 0.1.10 CLI tool for interacting with Grafana.
    Dashboard Linter Latest Linter for Grafana dashboards.

    Prometheus & Mimir¶

    Tool Version Description
    Promtool (Prometheus) 3.12.0 CLI tool for Prometheus rules and config.
    Mimirtool 3.1.0 CLI tool for managing Mimir and Alertmanager.
    Amtool (Alertmanager) 0.32.2 CLI for Alertmanager.
    Pint 0.85.0 Prometheus rule linter.

    Loki¶

    Tool Version Description
    LogCLI 3.7.2 Command-line interface to Grafana Loki.

    SLO Tools¶

    Tool Version Description
    Sloth v0.16.0 SLO generator and manager.
    Pyrra 0.10.0 SLO manager and service level objective tool.

    Kubernetes & TUIs¶

    Tool Version Description
    k9s 0.51.0 Terminal UI to manage Kubernetes clusters.
    ktop 0.5.3 Top-like resource viewer for Kubernetes.
    gonzo 0.4.2 TUI analyzer for streaming/OTLP logs.

    Collectors¶

    Tool Version Description
    Alloy 1.16.3 OpenTelemetry Collector distribution; alloy fmt / convert / validate for pipeline config.

    Python Environment¶

    The image is based on quay.io/jupyter/datascience-notebook:notebook-7.4.7 and includes additional packages:

    • tsfresh: Automatic extraction of relevant features from time series.
    • scikit-learn: Machine learning library.
    • pyEDM: Empirical Dynamic Modeling for time series.
    • pandas-datareader: Up-to-date remote data access for pandas.
    • papermill: Tool for parameterizing and executing Jupyter Notebooks.
    • seaborn: Statistical data visualization.
    • statsmodels: Statistical modeling and econometrics.
    • prophet: Additive time-series forecasting (trend + seasonality) used for anomaly scoring.
    • requests: HTTP client for the Prometheus/Mimir query API.
    • jupyterthemes: Custom themes for Jupyter.

    System Packages¶

    Standard utilities installed via apt: curl, ssh-client, git, wget, jq, vim, netcat-traditional, unzip, ca-certificates, gnupg.
